## 诸暨公交 · 长者易用版 v1.3.0

这一版**回到 v1.1.0 的页面结构**，只做三件事：把「到目的地还有几站」做成大字主角、加一个设置页、让到站提醒真的会响会震。

### 1. Tab 名称：出行

底部三个 Tab：**首页 / 出行 / 设置**。

### 2. UI 精简，突出「还有几站到达目的地」

- 出行结果卡第一行就是 `到目的地还有 19 站`（22px 粉色数字），旁边是「直达 / 换乘 1 次」
- 方案详情顶部大字条永远显示「到目的地还有 N 站」（35px），右侧「约 X 分钟 · HH:MM 到达」+「50路 还有 3 站到上车站」；**没有在线车辆也照样给数字**（按静态里程估算）
- 去掉了重复的汇总卡、卡片里的长说明与「换乘预留 5 分钟」等次要信息；方案标签直接写「50路 · 42 分钟」
- 首页没有收藏时整块隐藏，不留空白

### 3. 设置页（新增）

- **主题色**：玫瑰粉 / 天空蓝 / 松柏绿 / 暖橙，即时生效并记忆
- **提示音**开 / 关、**音量** 0–100（松手试听，WebAudio 合成，不占包体）、**震动**开 / 关
- **提醒轮询间隔**：10 / 15 / 20 / 30 秒
- **通知权限**：状态徽标（已开启 / 未开启 / 已关闭 / 不支持）+ 一键申请 + 去系统设置；开启提醒时若无权限会弹窗引导
- **清除缓存**（二次确认）、**关于**页

### 4. 到站提醒：响铃 + 震动 + 系统通知

- 到站时同时响铃、震动、发系统通知（锁屏 / 后台可见，点击回 App）
- Android 13+ 运行时申请 `POST_NOTIFICATIONS`，通知通道按「声音 / 震动」组合分建

### 5. 边界：网络异常自动降级

- 接口连续失败 → 顶部「实时数据已自动降级」+ 重试，站序 / 首末班 / 换乘 / 提醒照常可用
- 起终点选成同一个站会被直接拦下，不会残留上一次的方案
