## 三、关键场景说明

### 3.1 出行：站名直查（去掉线路展开）

- 起点 / 终点改成两个**直接输入框**（占位「输入起点站 / 输入终点站」），点击弹出站名选择弹层。
- 弹层只保留一个搜索框：输入即过滤（中文模糊匹配），**空查询时直接列出最近 5 个站点**，另有「我的位置」按直线距离排序。原先的「线路展开 → 选方向 → 选站」两级 Tab 已删除，减少长辈的点击层级。
- 弹层字号单独放大：搜索框 46px、站名行 15px / 50px 高（`.pick-stop`），一屏可见 6–7 项。
- 起点与终点相同时提示「起点和终点不能是同一个站点」，不生成方案。

### 3.2 出行结果：直达 / 换乘 / 附近可达同屏

- 规划顺序：**直达（有则不找换乘）→ 1 次换乘 → 2 次换乘**，每类最多 3 个方案。
- 「附近可达站点」始终渲染：起点 / 终点 1 公里内、按距离取最多 4 个，带直线距离与「有直达」标记，点击即把该站设为终点重查——当线路都绕远时，这是最实用的一条兜底路径。
- 每张卡带实时摘要：`还有 N 站 · 约 X 分钟`；无在线车辆时写明 `暂无车辆 · 按静态估算`，不编造数据。
- 实时查询只针对每个方案的第一段，最多 6 个方向，并发 3，避免弱网下首屏拖长。

### 3.3 方案详情：竖向换乘流程 + 「到目的地还有 N 站」

- 顶部 hero：左栏 **「到目的地还有 N 站」**（35px 白字 + 渐变底），右栏「约 X 分钟 · HH:MM 到达」，第二行「线路：还有 N 站 · 约 X 分钟到站」——只有**一处**给出「到上车站还有几站」，避免与高亮条重复。
- 流程：起点（粉点）→ 各乘车段（mid 圈）→ 换乘站 → 终点（绿圈），一条 rail 串起，长辈从上往下读即可。
- 每段卡片：线路徽标 + 往方向 + **下车站提醒铃铛** + 实时块（26px 大数字 + 「到上车站 · 约 X 分钟」+ 车牌 / 位置）+ `乘 N 站 / 公里 / 约 X 分钟` + 「查看全部车辆」。
- 数据三态文案：`正在获取实时车辆…`（首帧）→ 有车 `还有 N 站 · 约 X 分钟` → 无车 `第一段暂无车 · 按静态里程估算`；接口异常才额外显示「已自动降级」横幅。

### 3.5 到站提醒：响铃 + 震动 + 系统通知

- 触发链：`Reminder.fire()` → `ZJ.Sound.chime()`（响铃）→ `ZJ.UI.vibrate([400,150,400,150,700])`（震动）→ `ZJ.Notify.fire(title, body)`（原生通知）→ 应用内弹层。
- 网页环境无 `Capacitor.Plugins.ZjNotify`，`Notify.status()` 返回 `unsupported`，页面上明确写「当前环境不支持系统通知，到站时只在 App 内弹窗提示」，不做假开关。
- APK 内：Android 13+ 申请 `POST_NOTIFICATIONS`；通道按「声音 / 震动」四种组合分别创建（通道属性创建后不可修改）；`notify()` 在无权限时返回 `{shown:false, reason:'no-permission'}`，前端据此不再显示"已发送"。
- 提醒依赖实时接口，接口中断时状态显示「数据中断 / 暂停」，不会误报。

### 3.6 边界与降级

| 场景 | 表现 |
|---|---|
| 实时接口连续 2 次失败 | `ZJ.Api.degraded = true`；线路页顶部 `#lineBanner`、详情页顶部 `.degrade-banner` 显示「实时数据已自动降级为静态数据」+ 重试；静态站序、首末班、收藏、换乘、提醒照常可用 |
| 单段接口失败（详情页） | 该段显示「实时数据不可用」+ 重新获取，其余段正常 |
| 网络异常（全部接口抛错） | 数据卡「实时车辆暂不可用」+ 原因 + 重新获取；页脚注明「当前显示静态站点数据」 |
| 无直达线路 | 先给换乘方案，并始终附「附近可达站点」兜底；确实无方案时给空态提示 |
| 站点搜索无结果 | 弹层显示「没有找到包含「…」的站点，换一个关键词试试」 |
| 定位被拒绝 | 首页正常渲染，`ZJ.Geo.state === 'fail'`，出行页「我的位置」提示不可用，无横向溢出 |
| 收班时段 | 数据卡「已收班 / 当前时段已收班（06:20–17:50）」，有时刻表则给下一班计划发车，标注「静态时刻表估算」 |
| 安卓返回键 | 优先关闭详情页 / 弹层，返回后仍停留在原 Tab |

### 3.7 移动端适配

- 390×844 下首页、出行、设置、线路页、方案详情页 `scrollWidth ≤ innerWidth`，无横向滚动。
- 竖向时间轴站名单行省略；横向时间轴竖排站名最多 8 字省略；hero 第二行文案单行省略（已缩短为「线路：还有 N 站 · 约 X 分钟到站」）。
- 底部 Tab 固定，含 `safe-area-inset-bottom`；全屏页与弹层走历史栈，安卓返回键先关上层。

## 七、遗留与说明

6. 部分线路官方时刻表接口返回空数组，此时仅展示首末班与实时车辆。
7. 主题色改变的是品牌色与浅色底，未做系统深色模式适配（保证大字与高对比优先）。
