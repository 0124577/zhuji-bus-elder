## 诸暨公交 · 长者易用版 v1.2.0

面向长辈的公交出行小工具，三个 Tab：**首页 / 出行 / 设置**。本版把「出行」与「设置」重做，并接上了安卓原生通知。

### 本版新增

**出行：站名直查，不再展开线路选站**
- 起点 / 终点是两个直接输入框，点击弹出站名选择弹层（空查询直接列最近 5 站，另有「我的位置」）
- 一个搜索框搞定，减少长辈的点击层级

**出行结果：三类方案同屏**
- **直达方案** / **换乘方案** / **附近可达站点**（起点、终点 1 公里内，标注「有直达」，一点即查）
- 卡片直接给「还有 N 站 · 约 X 分钟」，无车时写「暂无车辆 · 按静态估算」

**方案详情：换乘流程 + 到目的地还有几站**
- 顶部大字「**到目的地还有 N 站**」（35px），右侧「约 X 分钟 · HH:MM 到达」
- 竖向换乘流程：起点 → 各乘车段 → 换乘站 → 终点，一条线读到底
- 每段实时块：大数字「到上车站 · 约 X 分钟」+ 车牌 + 位置，下车站可开提醒

**设置页（新增）**
- 主题色：玫瑰粉 / 天空蓝 / 松柏绿 / 暖橙，切换立即生效并记忆
- 提示音开 / 关、音量 0–100（松手试听，WebAudio 合成铃声，不占包体）
- 震动开 / 关
- 提醒轮询间隔：10 / 15 / 20 / 30 秒
- 通知权限：状态徽标（已开启 / 未开启 / 已关闭 / 不支持）+ 一键申请 + 去系统设置
- 清除缓存（二次确认）、关于页

**到站提醒：响铃 + 震动 + 系统通知**
- 到站时同时响铃、震动、发系统通知（锁屏 / 后台可见，点击回到 App）
- Android 13+ 运行时申请 `POST_NOTIFICATIONS`，通道按「声音 / 震动」组合分建

### 已知限制

- 官方实时接口收班后（约 18:00 后）多数线路无在线车辆，页面显示「暂无在线车辆 / 按静态估算」，不编造数据

- 发车时刻表部分线路官方返回空数组，此时只展示首末班
